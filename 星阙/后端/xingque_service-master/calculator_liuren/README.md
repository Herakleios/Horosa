# 星算 <star-calculator>

## 集合玄门相关的玄学算法

### 提供算法列表

#### 六壬 `calculate_liuren`

> 提供了六壬算法的实现

##### 入参：

1. `day` 日期时间对象
2. `birth` 出生日期时间对象，可选

##### 结果：

| 代码         | 名称  | 数据类型              | 说明                                        |
|------------|-----|-------------------|-------------------------------------------|
| datetime   | 日期  | `list[str]`       | 数组中的每个元素为 `[年、月、日、天]`                     |
| major, sub | 课体  | `str, str`        | 课体大类，课体小类                                 |
| shishen    | 天地盘 | `list[list[str]]` | 数组中的每个元素为 `[地盘、天盘、旬日、天将]`                 |
| lesson     | 四课  | `list[list[str]]` | 数组为**一二三四课**，每个元素为 `[上课，下课、旬日、天将]`        |
| passes     | 三传  | `list[list[str]]` | 数组为**上中下三传**，每个元素为 `[三传，旬日、天将、六亲]`        |
| xun        | 旬日  | `object`          | 包含旬首(start), 旬尾(end), 旬丁(ding), 旬空(empty) |
| month      | 月将  | `str`             | -                                         |
| ben        | 本命  | `list[str]`       | 根据生日推算本命，前提是birth有值                       |
| xing       | 行年  | `list[str]`       | 根据生日推算行年，前提是birth有值                       |
